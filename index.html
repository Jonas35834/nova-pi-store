Raspberry Pi OS Lite

🍓 Nova Pi Store Apps einfach installieren.

Ein leichter Web-App-Store für Raspberry Pi OS Lite. Verwaltet deinen Raspberry Pi bequem über SSH und einen Browser.

🚀 Installation 🛠️ Änderung anfragen

Was kann Nova Pi Store?

Nova Pi Store wurde speziell für Raspberry Pi OS Lite entwickelt. Du brauchst keine Desktop-Umgebung.

📦

Apps installieren

Installiere unterstützte Programme direkt über deinen Browser.

🔎

Apps suchen

Durchsuche die verfügbaren Programme und Kategorien.

🖥️

Für Lite

Keine grafische Desktop-Umgebung auf dem Raspberry Pi notwendig.

🔄

Aktualisierbar

Der Store kann über das eigene APT-Repository aktualisiert werden.

Installation

Installiere Nova Pi Store auf einem Raspberry Pi OS Lite System über APT.

sudo apt update sudo apt install nova-pi-store

Anschließend erreichst du die Weboberfläche standardmäßig über:

http://DEINE-PI-IP:8080
